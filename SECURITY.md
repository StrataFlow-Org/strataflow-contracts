# Security Policy

## 🔒 Reporting Security Vulnerabilities

The StrataFlow team takes smart contract security and non-custodial asset custody seriously. If you discover a vulnerability or security flaw in the smart contracts:

**Please DO NOT open a public issue.**

Instead, report it responsibly:
- Email: **security@strataflow.io**
- Subject: `[Vulnerability]: StrataFlow Contracts`

Please include:
1. Proof of concept (PoC) code or simulation steps using `soroban_sdk::Env`.
2. An assessment of potential impact (e.g. fund freezing, unauthorized release, replay attack).
3. Any proposed mitigations.

We will acknowledge receipt within 48 hours and work with you on remediation prior to public disclosure.
